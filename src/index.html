How to read this. Published counterparts are CTDL's own DECLARED_CORRESPONDENCE statements to CEDS terms (owl:equivalentClass, skos:narrowMatch, skos:relatedMatch), carried verbatim; today they cover only financial-aid and support-service code values. Shared ground means an element of another standard was judged onto a CEDS card and onto a CTDL card. EDUcore keeps its hubs as peers that never chain, so this is co-coverage evidence, not a CEDS–CTDL mapping: each judgment is an inferred pick with its own relation and confidence, and both hops are shown separately. Spokes use this hub only means other standards map to the property but none of those elements also lands in the other hub; it does not show the other hub lacks the concept. CTDL-ASN and CTDL-QData are not part of the CTDL hub, so nothing maps to them. Shared ground counts only property-tier cards with derived judgments. Stage and topic come from name rules on each class, not from the graph, so treat placement as a reading aid. Data from the EDUcore knowledge graph.
